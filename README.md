## 🚀 Key Features

* **🌐 Local & Global Toggling:** Instantly spin up local HTTP servers or expose them globally using **Cloudflare Tunnels** or **lhr (`localhost.run`)**.
* **⚡ Live Reloading:** Automatically injects an event-source script into HTML pages so your browser instantly reloads whenever you modify files locally.
* **🔄 Multi-Server Manager:** Run multiple concurrent servers on independent dynamic ports, manage them independently, and open either local or global endpoints directly from a popup menu.
* **⌨️ Global Hotkeys:** Control and trigger local/global server creation instantly using customizable keyboard shortcuts (e.g., `ctrl+alt+h`, `ctrl+alt+shift+h`).
* **🎨 Custom Themes & Animated Backgrounds:** Switch between Light, Dark, Dark Blue themes, or set custom animated GIFs as your application background.
* **📦 Portable & Standalone:** Bundled with embedded binaries (`cloudflared`) and packaged cleanly into a single Windows executable via PyInstaller.
